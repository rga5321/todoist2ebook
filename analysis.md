# Codebase Analysis: `todoist2ebook`

The `todoist2ebook` project is a Python-based utility that extracts saved articles and links from a specified Todoist project, converts them into an ebook (EPUB format), and optionally emails the resulting files to a Kindle or other e-reader.

## Key Components

1.  **`main.py` (Orchestrator)**
    *   Acts as the main entry point for the application.
    *   Loads environment variables for configuration (Todoist credentials, SMTP settings for emailing, etc.).
    *   Invokes the Calibre command-line tool (`ebook-convert`) to build the initial EPUB using a custom Calibre recipe.
    *   Calls the `epub_qr` module to add QR codes to the generated EPUB.
    *   Performs a format conversion round-trip: EPUB → MOBI → EPUB. This produces a "backup" EPUB (`-backup.epub`) alongside the original (`-original.epub`). This process is meant to normalize the ebook structure to improve compatibility with Amazon's "Send to Kindle" service.
    *   Sends both the original and backup EPUB files via email to the configured destination address.

2.  **`Todoist.recipe` (Calibre Recipe)**
    *   A custom Calibre `BasicNewsRecipe` script that defines how to fetch and parse the content.
    *   Uses the Todoist API (v1) to fetch tasks from a specific `TODOIST_PROJECT_ID`.
    *   Extracts URLs from the task content (handling both raw URLs and Markdown-formatted links).
    *   Filters out articles based on an exception list (`URL_KEYWORD_EXCEPTIONS`).
    *   Groups the extracted links by domain and returns them to Calibre, which then fetches the web content and compiles it into an ebook.
    *   Can optionally close (archive) the tasks in Todoist after successfully fetching them (`ARCHIVE_DOWNLOADED`).

3.  **`epub_qr.py` (Post-processing)**
    *   Provides the `add_qr_to_epub` function.
    *   Unzips the EPUB generated by Calibre.
    *   Iterates through the HTML/XHTML files to find the original article URL (looking for `rel="calibre-downloaded-from"`).
    *   Generates a QR code image for the URL using the `qrcode` library.
    *   Injects an `<img>` tag containing the QR code at the end of the article's `<body>`.
    *   Repacks the EPUB file with the new images and modified HTML.

## Workflow Summary

1.  **Extract:** The script connects to the Todoist API, retrieves tasks from a specified project, and extracts web URLs from them.
2.  **Convert:** Calibre downloads the content from the URLs and packages it into an EPUB file.
3.  **Enhance:** A QR code pointing to the source URL is appended to each article in the EPUB.
4.  **Normalize:** The EPUB is converted to MOBI and back to EPUB to ensure it is structurally sound for Amazon's Kindle delivery.
5.  **Deliver:** The generated ebooks are emailed to the user's e-reader.
